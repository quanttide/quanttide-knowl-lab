# 项目质量审计章程

**第一章 总则**

**第一条 定义**

项目质量审计是对项目质量管理活动的独立、系统性审查，旨在评估项目过程与可交付成果是否符合既定要求、期望和适用标准，并确认质量管理体系的有效性。

**第二条 审计目标**

项目质量审计致力于实现以下目标：

（一）核实项目产出是否符合预定的需求、规范和标准。
（二）识别并揭示可能导致质量问题的因素与控制薄弱点。
（三）评估过程效率和效果，推动缺陷预防。
（四）为客户、干系人的满意度和信任度提供独立验证。
（五）降低因返工、缺陷修复和客户投诉带来的成本和风险。

**第三条 审计原则**

（一）**符合性与适用性并重**：审计关注质量是否"符合要求"且"适合使用"，而非评估是否超出需求范围。
（二）**预防导向**：重点关注预防成本投入与预防措施的有效性，而非仅检查事后修复。
（三）**持续改进**：以审计发现驱动PDCA循环，推动过程与成果的不断优化。
（四）**客户视角**：将客户和关键干系人的满意度作为衡量质量成效的终极参照。
（五）**管理层责任**：审计应评估管理层在质量文化营造和资源保障方面的履职情况。

**第二章 审计范围与过程**

**第四条 审计覆盖**

项目质量审计覆盖以下三个主要过程：

（一）**规划质量管理**：审查质量规划活动的充分性与合理性。
（二）**管理质量（质量保证）**：审查过程执行与质量管理体系的一致性。
（三）**控制质量**：审查可交付成果的验证活动及其结果。

**第五条 规划质量管理审计**

（一）**审查要点**：
1. 是否识别了项目及其可交付成果的质量要求、标准与成功指标。
2. 是否确定了衡量质量的方法和工具，包括质量指标、审计、测试方法等。
3. 是否制定了质量管理计划，职责分工、时间安排与资源配置是否明确。
4. 是否选择了适当的质量成本策略，预防成本、评估成本、失败成本的分配是否合理。
5. 是否编制了质量测量指标，如缺陷率、测试通过率、客户满意度评分等。

（二）**审查对象**：质量管理计划、质量测量指标、质量核对单等。

**第六条 管理质量审计（质量保证审计）**

（一）**审查要点**：
1. 过程审计：检查项目活动是否遵循既定流程和标准。
2. 过程分析：是否识别了过程中的瓶颈与低效之处，并推动改进。
3. 是否采用了质量改进方法，包括PDCA循环、六西格玛、精益、根本原因分析等。
4. 是否开展了质量意识培训，团队成员对质量要求的认知是否到位。
5. 是否分析了来自控制质量过程的数据，并对系统性问题进行根本性解决。

（二）**审查对象**：质量报告、测试与评估文件、变更请求、过程更新记录等。

**第七条 控制质量审计**

（一）**审查要点**：
1. 是否依据质量标准对可交付成果进行了检查，包括代码审查、设计评审、产品测试等。
2. 质量控制测量结果是否与质量标准进行了有效比对。
3. 是否识别并记录了缺陷、偏差、不合格项及其原因。
4. 合格可交付成果是否经正式批准，不合格品是否被有效拦截。
5. 是否推动了对不合格可交付成果的纠正或返工。

（二）**审查对象**：质量测量结果、核实的可交付成果记录、工作绩效信息、变更请求、质量控制图表等。

**第三章 质量成本审计**

**第八条 质量成本分类审查**

审计应对以下三类质量成本进行核实与评价：

（一）**预防成本**：评估为预防缺陷发生所投入资源的充分性与有效性。
（二）**评估成本**：评估质量检查活动的效率与覆盖程度。
（三）**失败成本**：统计因内部失败（返工、报废）和外部失败（客户投诉、索赔）所产生的成本，追溯其根因。

**第九条 成本策略审计**

审计应评估项目是否优先保障预防成本的投入，以实现整体质量成本的最优化。

**第四章 审计发现与报告**

**第十条 审计发现分类**

审计发现按以下三类呈现：

（一）**正面发现**：证明项目质量管理中的有效做法与优势。
（二）**改进发现**：识别质量管理的短板与改善空间。
（三）**现状发现**：对质量管理运行状态进行客观描述。

**第十一条 审计报告**

审计完成后应形成书面报告，内容包括：

（一）审计范围与过程。
（二）各审查要点的评估结论。
（三）识别出的正面发现、改进发现与现状发现。
（四）系统性问题分析与改进建议。
（五）质量成本评估。

**第五章 审计价值**

**第十二条 审计意义**

项目质量审计不仅是核查"有无犯错"，更是为了：

（一）验证项目价值实现：确认质量是否保障了项目预期价值的落地。
（二）揭示隐性成本：识别返工、废品、客户投诉和支持成本的根本原因。
（三）控制风险：预警质量缺陷可能带来的声誉、法律和安全风险。
（四）提升效率：通过审计发现驱动过程优化，减少浪费。
（五）增强信任：为干系人提供独立的质量保证，巩固客户关系与市场竞争力。

**第六章 附则**

**第十三条 适用与调整**

本章程适用于公司各类项目的质量审计工作。不同项目类型可按实际情况选用具体的审计工具与技术。

**第十四条 解释与修订**

本章程由审计委员会负责解释，修订须经公司代表大会批准。

**第十五条 生效**

本章程经公司治理机构审议通过，自发布之日起生效。
