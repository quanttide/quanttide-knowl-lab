# 审计章程

**第一条 审计目的**

建立"规则制定→审计计划→发现问题→驱动改进"的闭环机制，以建设性审计原则为导向，从事后验证延伸至事中评估，推动业务管理精细化，实现从防御性审计向建设性审计的转变。

**第二条 运作机制**

（一）**合规需求提报**：任何岗位均可根据工作需要提交合规需求，作为审计规则制定与审计计划编制的输入。

（二）**规则与计划制定**：审计据此制定对应规则与审计计划，明确信息提供要求，向相关责任人发出配合指令。

（三）**审计统筹与推进**：通过周会机制统筹各项审计问题，协调整改进展，倒逼事前管理与事中管理的精细化。

（四）**闭环迭代**：审计发现驱动规则修订与管理改进，形成持续迭代的闭环。

**第三条 审计发现的定义与分类**

"审计发现"为中性术语，采用以下三类方式呈现：

（一）**正面发现**：证明业务运行中的既有优势与有效做法。

（二）**改进发现**：识别业务运行中存在的短板与改善空间。

（三）**现状发现**：对业务运行状态进行客观描述，不作价值判断。

**第四条 工作原则**

（一）**建设性审计原则**：审计以提供证据、发现价值为导向，而非以发现问题为目的。

（二）**事中评估原则**：强调过程监控与动态调整，遵循"标准分解→产出追踪"的持续改进逻辑。

（三）**事后审计原则**：强调结果验证与正式结论，遵循"证据收集→报告生成"的闭环验证逻辑。

**第五条 审计授权原则**

（一）**审计权定义**：审计权指事后核查问题、对业务结果与制度执行提出批评、建议及优化意见的权力。

（二）**授权原则**：审计授权基于个人在组织中的专业能力与影响力，与职务无直接关联，授予对象为资深成员或领域专家。

**第六条 工作方法**

审计工作采用绩效审计模式，参照质检逻辑，以证据为基础，对业务运行的经济性、效率性和效果性进行评估。

**第七条 文档体系**

审计文档分三级管理：

（一）**L1 业务/职能审计规则**：规定各项业务或职能的审计标准与合规要求。

（二）**L2 审计计划**：明确审计范围、时间安排、资源分配与责任人。

（三）**L3 审计发现与诊断**：记录审计发现的具体内容及诊断分析。

**第八条 信息追溯机制**

当前阶段，财务部门可借助审计机制建立信息追溯机制。未来若合规需求频密，需考虑设置专职审计岗位或部门，以保障审计体系持续运转。

**第九条 附则**
